## 当前实现

- 基于 Python 标准库 `http.server`，单文件 `web_search_server.py`，无第三方依赖。
- 实现 Anthropic Messages API 的 `POST /messages`，识别请求体中的 `web_search_20250305` server tool。
- 真实搜索只走 **DuckDuckGo HTML 版**（`https://html.duckduckgo.com/html/?q=...`），
  由 `_perform_real_search()` 按结果块正则解析标题、链接与摘要；请求失败或超时会返回
  「search failed」响应，不会回退到模拟数据。
- 响应体包含文本块（含 `citations`）与 `web_search_tool_result` 块。
