## 启动

```bash
python3 web_search_server.py
python3 web_search_server.py --port 8080 --api-key my-secret-key
```

命令行参数：`--host`、`--port`、`--api-key`、`--cors-origin`。

代码实际读取的环境变量：`DEEPSEEK_API_KEY`、`SEARCH_SERVER_HOST`、
`SEARCH_SERVER_PORT`、`SEARCH_SERVER_CORS_ORIGIN`。
